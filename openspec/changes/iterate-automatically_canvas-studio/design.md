# Design: Canvas Studio Iterate-Automatically (Phase 1) - A Defect Fix Focus

This OpenSpec change encapsulates a defect-fix cycle focused on stabilizing core Canvas Studio interactions during daily iterate-automatically runs:
- Avatar group left/top drift on drag
- Mask coordinate drift during orientation changes
- Canvas resize behavior for offsets
- Transformer mirroring width correctness
- RenderElement picture type handling

This change is scoped to addressing reliability and UX issues, not new features.
